# ตรวจสอบจุดภายในโพลิกอน c# – ตรวจสอบเรขาคณิตที่มีจุดอื่น

## บทนำ
หากคุณกำลังสร้างโซลูชัน **geospatial analysis .NET** คุณจะต้องเผชิญกับคำถามแรกคือว่าตำแหน่งเฉพาะ (จุด) อยู่ภายในพื้นที่ที่กำหนด (โพลิกอน) หรือไม่ ในบทเรียนนี้เราจะพาคุณผ่านการทำงาน **check point inside polygon** อย่างครบถ้วนโดยใช้ไลบรารี **Aspose.GIS .NET** ไม่ว่าคุณจะสร้างบริการ geofencing, UI การทำแผนที่, หรือ pipeline การวิเคราะห์เชิงพื้นที่ ขั้นตอนต่อไปนี้จะทำให้คุณพร้อมใช้งานในไม่กี่นาที

## คำตอบอย่างรวดเร็ว
- **อะไรคือ “check point inside polygon c#”?** เป็นการสอบถามเชิงพื้นที่ที่คืนค่า true เมื่อเรขาคณิตจุดอยู่ภายในเรขาคณิตโพลิกอนอย่างสมบูรณ์  
- **ไลบรารี .NET ใดที่ทำการตรวจสอบนี้?** Aspose.GIS for .NET มีเมธอด `SpatiallyContains` และ `Within` สำหรับการทดสอบการครอบคลุมอย่างรวดเร็ว  
- **ฉันต้องการไลเซนส์หรือไม่?** มีการทดลองใช้ฟรี; จำเป็นต้องมีไลเซนส์เชิงพาณิชย์สำหรับการใช้งานในสภาพแวดล้อมการผลิต  
- **รองรับ .NET 6+ และ .NET Core หรือไม่?** ใช่ – Aspose.GIS รองรับ runtime ของ .NET สมัยใหม่อย่างเต็มที่  
- **การดำเนินการใช้เวลานานเท่าไหร่?** ประมาณ 10 นาทีเพื่อคัดลอกโค้ดและรันตัวอย่าง  

## การตรวจสอบจุดภายในโพลิกอน c# คืออะไร?
การทดสอบ **check point inside polygon** จะกำหนดว่าพิกัดของอ็อบเจกต์ `Point` อยู่ภายในขอบเขตของอ็อบเจกต์ `Polygon` หรือไม่ ใน C# ปกติจะทำโดยไลบรารีเรขาคณิตที่ใช้ алгоритм Ray Casting หรือ Winding Number. Aspose.GIS แยกรายละเอียดเหล่านั้นและให้ API แบบบรรทัดเดียว: `polygon.SpatiallyContains(point)`

## นำเข้า namespace
Namespace ต่อไปนี้ให้การเข้าถึงประเภทเรขาคณิตของ Aspose.GIS และการดำเนินการเชิงพื้นที่  

```csharp
using Aspose.Gis.Geometries;
using System;
using System.Collections.Generic;
using System.Linq;
using System.Text;
using System.Threading.Tasks;
```

## ขั้นตอนที่ 1: กำหนดอ็อบเจกต์เรขาคณิต
`Polygon` กำหนดพื้นที่ปิด, ส่วน `Point` แสดงตำแหน่งพิกัดเดียว  

```csharp
var geometry1 = new Polygon();
geometry1.ExteriorRing = new LinearRing(new[]
{
    new Point(0, 0),
    new Point(0, 4),
    new Point(4, 4),
    new Point(4, 0),
    new Point(0, 0),
});
geometry1.AddInteriorRing(new LinearRing(new[]
{
    new Point(1, 1),
    new Point(1, 3),
    new Point(3, 3),
    new Point(3, 1),
    new Point(1, 1),
}));
var geometry2 = new Point(2, 2);
```

## ขั้นตอนที่ 2: ตรวจสอบการครอบคลุมเชิงพื้นที่
`SpatiallyContains` ตรวจสอบว่าเรขาคณิตหนึ่งครอบคลุมเรขาคณิตอีกอันอย่างสมบูรณ์หรือไม่  

```csharp
Console.WriteLine(geometry1.SpatiallyContains(geometry2)); // False
```

## ขั้นตอนที่ 3: กำหนดเรขาคณิตอื่น
ที่นี่เราจะสร้าง `Point` ตัวที่สองที่ตั้งอยู่ในวงแหวนภายนอกของโพลิกอน  

```csharp
var geometry3 = new Point(0.5, 0.5);
```

## ขั้นตอนที่ 4: ตรวจสอบการครอบคลุมเชิงพื้นที่อีกครั้ง
การรันการตรวจสอบการครอบคลุมเดียวกันกับจุดใหม่จะคืนค่า `true`, ยืนยันว่าจุดนั้นอยู่ภายในขอบเขตภายนอกของโพลิกอนจริงๆ  

```csharp
Console.WriteLine(geometry1.SpatiallyContains(geometry3)); // True
```

## ขั้นตอนที่ 5: ฟังก์ชันที่เทียบเท่า
`Within` คืนค่า true เมื่อเรขาคณิตอยู่ภายในเรขาคณิตอื่นอย่างเต็มที่  

```csharp
Console.WriteLine(geometry3.Within(geometry1)); // True
```

| Issue | Why it happens | Fix |
|-------|----------------|-----|
| **ผลลัพธ์ `false` ที่ไม่คาดคิด** | จุดอยู่ภายในช่องว่าง (วงแหวนภายใน) ของโพลิกอน. | ตรวจสอบให้แน่ใจว่าคุณกำลังทดสอบกับโพลิกอนที่ถูกต้องหรือใช้ `geometry1.ExteriorRing` สำหรับโพลิกอนง่ายที่ไม่มีช่องว่าง. |
| **NullReferenceException** | อ็อบเจกต์เรขาคณิตไม่ได้ถูกสร้างก่อนเรียก `SpatiallyContains`. | สร้างอ็อบเจกต์โพลิกอนและจุดทั้งสองก่อนเรียกใช้เมธอดเชิงพื้นที่. |
| **ประสิทธิภาพช้าลงเมื่อทำงานกับชุดข้อมูลขนาดใหญ่** | สร้างอ็อบเจกต์เรขาคณิตซ้ำๆ ภายในลูป. | ใช้อ็อบเจกต์เรขาคณิตเดิมซ้ำหรือประมวลผลเป็นชุดโดยใช้ `GeometryCollection`. |
